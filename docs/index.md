# SpectraMap (SpMap)

Welcome to the SpectraMap documentation!

SpectraMap is a hyperspectral package for spectroscopists in Python. It includes standard tools such as reading, preprocessing, processing, and visualization. The design is focused on hyperspectral images from Raman datasets, but it is easily extended to other spectroscopies.

## Getting Started

Please see the README on the [GitHub repository](https://github.com/MicroscopeMaestro/spectramap) for installation instructions and quick start examples.
